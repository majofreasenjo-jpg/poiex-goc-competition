## Five receiver-native controls

1. **Semantic Binding Invalidation** — authority/scope/target/policy binding changes invalidate legacy decision artifacts for final disposition and require recomputation.
2. **Memory Readback Audit** — persistent history is not called operationally load-bearing memory unless matched-current tests show memory-state changes split the declared future decision/action kernel.
3. **Sequential Stage Freshness** — a downstream stage consumes the receipted post-stage output, not stale pre-gate input, unless a verified noninterference certificate establishes equivalence.
4. **Observer Non-Mint** — evaluator/model/window/threshold/routing reparameterization cannot mint evidence or progress when system state and independent evidence roots are unchanged.
5. **Open-World Registry Reopening** — a new admissible rival reopens global coverage while unchanged pair-local certificates can remain valid within their declared scope.
